- **🔒 Type-Safe** - 100% TypeScript codebase
- **♿ Accessible** - shadcn/ui accessible components

## 🎯 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/Mostafa-SAID7/tukly-local-logistics.git
cd tukly-local-logistics

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:8080](http://localhost:8080) — your app is live! 🎉
